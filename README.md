here the commands :
Utilities

/ping: shows the bot's latency
/bonjour: the bot says hello
/de [faces]: rolls a die (6 sides by default)
/pileouface: heads or tails
/avatar [member]: shows a member's avatar (yours by default)
/sondage question: creates a ✅/❌ poll, public so others can vote
/aide: lists the commands

AI

/ia question [prive]: asks the AI a question, with a private reply by default
/reset: clears the conversation memory
/personnalite text: sets the AI's personality on the server (leave empty to reset), restricted to those who manage the server
/canalia actif: makes the AI reply to every message in the channel, restricted to those who manage channels

Moderation (restricted to members with the matching Discord permission)

/kick member [reason]: kicks a member
/ban member [reason]: bans a member
/unban user_id: unbans a user using their ID
/timeout member minutes [reason]: temporarily mutes a member, from 1 minute to 28 days
/untimeout member: removes the timeout
/clear amount: deletes 1 to 100 messages in the channel

Chatbot mode (no command needed)

Mention the bot: @Bot your question
Reply to one of its messages to continue the conversation
Write in an AI channel (enabled with /canalia)
Attach up to 3 images for it to analyze
Ask for a moderation action in plain language: @Bot mute @Paul 10 minutes for spam, @Bot delete the last 20 messages or @Bot ban @Jean. Only moderators can do this, and kick and ban require a button confirmation.
